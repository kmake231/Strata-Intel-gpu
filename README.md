# Strata for an Intel GPU

This repository is [Strata](https://github.com/Niko1221/Strata) with notes for running it on an Intel Arc GPU.

The setup notes are in [SetupGuideIntelgpu](SetupGuideIntelgpu/):

- [strataSetup.md](SetupGuideIntelgpu/strataSetup.md) — Terminal setup, text only, on Ubuntu with an Arc A750
- [strataVision.md](SetupGuideIntelgpu/strataVision.md) — turn pictures on after that Terminal setup
- [strataSetupVision.md](SetupGuideIntelgpu/strataSetupVision.md) — one path from a blank Ubuntu PC to Gyro-S with pictures on

This repo already includes the container path change in `sycl/serve/strata-sycl.sh` that the vision notes describe.
